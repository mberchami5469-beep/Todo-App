# ✅ Todo List – React Application

A simple and interactive Todo List application built with **React** and **Vite**. This project allows users to manage their daily tasks through a clean and easy-to-use interface.

## 📌 Project Overview

The Todo List application is designed to help users organize their tasks and keep track of their daily activities. It demonstrates the fundamentals of React, including components, props, state management, and event handling.

## ✨ Features

- **Add Tasks:** Create new tasks using the input field.
- **Complete Tasks:** Mark tasks as completed with a checkbox. Completed tasks appear with strikethrough text.
- **Delete Tasks:** Remove tasks from the list.
- **Dynamic Interface:** Automatically update the displayed task list when the user interacts with the application.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React | Building reusable UI components |
| Vite | Development environment and build tool |
| JavaScript (ES6+) | Application logic |
| CSS3 | Styling and layout |

## 🧠 React Concepts Practiced

This project helped practice the following React concepts:

- **useState:** Managing the task list and input value.
- **Components:** Organizing the application into reusable components.
- **Props:** Passing task information and functions to `TodoItem`.
- **map():** Rendering the list of tasks dynamically.
- **key:** Providing unique identifiers for rendered list elements.
- **Event Handling:** Managing `onClick` and `onChange` events.
- **Conditional Rendering:** Displaying completed tasks differently.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/TON-USERNAME/todo-list.git
```

### 2. Navigate to the project folder

```bash
cd todo-list
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
